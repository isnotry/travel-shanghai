## 它是什么

一份**给真实行程用**的上海旅行指南，不是景点介绍合集。58 个景点，每个都写清四件事：门票多少、开放到几点、建议留多久、从哪个地铁口出来。

形态是**三个静态 HTML + 原生 CSS/JS**，没有 npm、没有框架、没有后端，双击 `index.html` 就能跑，丢到任意静态托管上也能跑。

中英两版**不是互译**：中文版写给国内读者（地铁、抢票、天气穿搭、避坑），英文版写给入境游客（240 小时过境免签、支付、网络与访问受限的应用）。同一个景点有两套文案，两版还各有自己的配色与排版。

## 特性

- **58 个景点，7 个分类** —— 城市地标 9、园林古镇 11、博物馆 12、艺术街区 12、演出娱乐 4、亲子乐园 6、寺庙古建 4；每张卡片都带门票、开放时间、建议游玩、地铁出口
- **闭馆日是第一等公民** —— 20 个带闭馆信息的场馆，顶部通栏提醒 + 卡片红色标签，另有 `周一可去` 一键筛掉周一闭馆的
- **两支读者，两套内容** —— 中文版讲交通、抢票、天气、支付；英文版讲签证、网络、无现金支付。两版各 6 张须知卡，主题完全不同
- **搜索同时吃两种语言** —— 中文界面里输 `Bund` 也能命中外滩；名称、副标题、简介、地铁站、分类名都在索引里
- **收藏** —— 卡片右上角星标，收藏夹变成景点区顶部的一条快捷入口，只存在本机浏览器
- **详情弹层** —— 点卡片打开，除了四行硬信息还有 3~5 条贴士：最佳机位、几点去人少、别在哪儿买东西
- **3 条现成行程** —— 经典 3 日、亲子 5 日、深度 7 日，顺序按各自闭馆日排过
- **不只是景点** —— 6 张行前须知、10 条避坑清单、9 道本帮味道、6 个紧急电话、6 条生活常识、7 个必装 App
- **两套视觉** —— 中文版是暖米黄 + 朱红印章 + 宋体标题的新中式排版；英文版是深色影院感 + Georgia 的杂志风
- **零依赖零构建** —— 三个 HTML、四个源文件、60 张图，没有 `node_modules`，没有编译步骤

## 景点数据口径

每个景点是 `assets/js/data.js` 里的一条记录，中英各一份文案。字段含义：

| 字段 | 含义 | 说明 |
| --- | --- | --- |
| `price` | 门票 | 写实价；免费景点写「免费」/ `Free` |
| `hours` | 开放时间 | 24 小时开放的写「全天开放」 |
| `duration` | 建议游玩 | 区间写法，如 `1.5 – 2 小时` |
| `metro` | 交通 | 线路 + 站名 + 出口；多个入口用分号分开 |
| `stars` | 推荐度 | 5 分制，渲染成 `★★★★☆` |
| `closed` | 闭馆日 | 为 `null` 表示全年开放；有值则中英各一段文案 |
| `img` | 配图 | `assets/img/<id>.jpg`；缺省时回退成 emoji 占位块 |
| `cat` | 分类 | 取 7 个分类 id 之一，决定它落在哪个筛选项下 |

票价与开放时间都是**参考值**，页面底部统一声明「以景区官方渠道当日公示为准」。

## 筛选与搜索怎么算

```
isClosedMonday(a) = a.closed 存在 且 当前语言文案里含「周一」/ MONDAY

搜索索引 hay = 中文名 + 英文名 + 中文副标题 + 英文副标题
              + 中文简介 + 英文简介 + 中文地铁 + 英文地铁 + 当前语言分类名

入选条件 = 分类匹配 && !(周一可去 && isClosedMonday(a)) && hay 含关键词（忽略大小写）
```

- `周一可去` 是**减法**：勾上后只过滤掉判定为周一闭馆的场馆，`closed` 为 `null` 的开放街区（外滩、南京路、武康路这类）永远保留
- 闭馆判定读的是**文案**而不是结构化日期字段 —— 想让某个场馆响应 `周一可去`，中文写「周一闭馆」、英文写 `Closed Mondays` 即可生效
- 搜索是大小写不敏感的子串匹配，中英字段同在一个索引里，所以中文版里输英文也能命中

## 数据与隐私

没有后端、没有埋点、没有 cookie、没有第三方请求：图片、样式、脚本全部同源打包，断网也能打开。

只用到两个 `localStorage` key：

| Key | 内容 | 说明 |
| --- | --- | --- |
| `shanghai-lang` | `zh` / `en` | 入口页记住上次选的版本，只在那一半印一行小字，**不自动跳转** |
| `shanghai-favs` | 收藏的景点 id 数组 | 形如 `["bund","yuyuan"]`，清掉等于清空收藏 |

`localStorage` 不可用时（隐私模式、某些 `file://` 场景）收藏只是不持久化，页面照常用。

## 开发说明

- 内容全在 `assets/js/data.js`（58 个景点）和 `assets/js/content.js`（须知、行程、美食、速查、界面文案），改完刷新浏览器即可，**没有编译步骤**
- 每个景点必须有 `zh` 和 `en` 两份文案，字段一一对应；`closed` 不允许只写一半
- 新增一个景点：把 16:10 的图存成 `assets/img/<id>.jpg`（长边 1000px 够用）→ 在 `data.js` 对应分类段落里加一条 → 刷新
- 中文版主题变量在 `theme-zh.css`，英文版在 `theme-en.css`；`common.css` 只管结构，语言相关的样式别往里塞
- `tools/build.js` 是给「会拦 CSS/JS 子资源」的托管平台用的：它把样式和脚本内联进 HTML，产出可整体上传的 `dist/`。GitHub Pages 不需要这一步
- 推到 `main` 后 `.github/workflows/pages.yml` 会把 `index.html` / `zh` / `en` / `assets` 发布到 GitHub Pages（仓库的 Pages 源需设为 **GitHub Actions**）

## 浏览器支持

Chrome / Edge / Safari / Firefox 现代版本，以及 iOS / Android 移动浏览器。只用到 ES5 语法，唯一的现代 API 是 `IntersectionObserver`（卡片入场动画），缺失时卡片直接显示、不影响内容。响应式布局在 760px 以下切单列，入口页两半由左右并排改为上下堆叠。
